# Development Setup

## Overview

This section explains how to set up the software development environment for the Lunar Rover Digital Twin project.

## Required Software

The following tools are used for project development:

- **Unity Hub:** Used to manage Unity installations and projects.
- **Unity Editor:** Used to develop and run the lunar rover simulation.
- **Git:** Used for version control and tracking project changes.
- **GitHub:** Used to share project files and collaborate with team members.
- **Cesium for Unity:** Used to create and integrate the lunar environment.

## Project Setup

1. Install Unity Hub.
2. Install the Unity Editor version used by the team.
3. Clone the team's GitHub repository.
4. Open the Unity project through Unity Hub.
5. Allow Unity to import the project assets and packages.
6. Open the lunar environment scene.
7. Press Play in Unity to run the simulation.

## Development Tools

The team uses Unity to develop the rover, lunar terrain, environmental objects, physics, and software integration.

GitHub is used to manage project updates and collaborate across the development team.

## Notes

Team members should use the same Unity Editor version and project packages to maintain compatibility.
